# NothingLauncher for Nothing lovers

A minimalist Android launcher with a clean "nothing" aesthetic.

## Branching (GitFlow)

| Branch | Purpose |
|--------|---------|
| `main` | Latest stable release (protected; only `release/*` can merge). |
| `develop` | Integration branch for all features/fixes. |
| `release/x.y.z` | Release cuts, branched from `develop`. Only these merge to `main`. |

See [CLAUDE.md](CLAUDE.md) for the full workflow and build commands.
