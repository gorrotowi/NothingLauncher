# TV Debloated Store — Investigación y plan

Reportes HTML para evaluar la idea de una app/tienda de "homescreens debloat"
para TVs Android, nacida del trend de usar agentes de IA (Claude Code) para
limpiar televisores.

## Contenido

| Archivo | Contenido |
|---------|-----------|
| `index.html` | Resumen ejecutivo y navegación |
| `01-market-and-trend.html` | Mercado, trend, audiencia, competencia |
| `02-implementation.html` | Arquitectura, formato de temas, seguridad, stack |
| `03-distribution-and-monetization.html` | Canales de distribución y monetización ética |
| `04-roadmap.html` | Plan por fases e hitos |
| `development-plan.md` | Plan ejecutable con checklist por fase |

## Cómo leer

Abre `index.html` en el navegador (los reportes son autocontenidos, sin
dependencias externas).

## Nota metodológica

Los reportes se redactaron sin acceso a internet en el entorno de generación;
los datos de mercado se basan en conocimiento previo de la industria
(2024–2026) y cada sección incluye una **lista de verificación** de fuentes a
confirmar antes de invertir.
